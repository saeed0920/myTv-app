# Changelog

## 1.1.0

- Phone videos/photos/audio: native file picker, streamed upload progress/cancel, upload-and-play on TV.
- Library downloads via phone share sheet; delete confirmation retained.
- Temporary RAM-backed photos: previous/next, end-and-clear, no permanent library copy.
- Box proxy settings: Xray/V2Ray share links, custom HTTP proxy, direct mode.
- Bluetooth power/discoverability, connect/disconnect, trust and confirmed forget.
- Website playback parity: source, 480p, available 30 FPS variants, audio, proxy and FPS choices.
- Opt-in TV JPEG preview; polling stops off-screen/backgrounded.
- App version displayed in Box; Android versionCode 3 / iOS buildNumber 3.

Requires matching box controller for safe upload and slides capabilities. APK workflow builds three ABI variants. Native phone/box testing remains required; controller not automatically deployed.
